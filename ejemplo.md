# visual-md

Aplicación GTK3 para ver y editar texto en una ventana translúcida.

## Características

- Ventana movible y siempre encima.
- Fondo translúcido ajustable.
- Edición de texto y Markdown.
- Abrir, guardar y recargar.
- Copiar, pegar y copiar todo.
- Fuente monoespaciada.

## Atajos

- `Ctrl+O`: abrir.
- `Ctrl+S`: guardar.
- `Ctrl+Shift+S`: guardar como.
- `Ctrl+R`: recargar.
- `Ctrl+Q`: salir.
- `Ctrl` + `+` / `Ctrl` + `-`: opacidad.
